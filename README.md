## Requisitos

- Python 3.10 ou superior
- pip

## Execução

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute:

```bash
python app.py
```

Acesse no navegador:

```text
http://127.0.0.1:5000
```

O banco `unidin.db` é criado e populado automaticamente na primeira execução.
